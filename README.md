# Курсовий проєкт: Вебсайт маркетингової агенції "RUBY" 

Практична реалізація багатосторінкового адаптивного сайту для компанії, що займається просуванням брендів.

##  Живе посилання на проєкт
* **Проєкт на GitHub Pages:** [Переглянути сайт](https://voloda27.github.io/ruby-agency-website/)

---

##  Етапи розробки
1. **Аналітичний етап:** Розбір дизайн-макету у Figma та планування структури.
2. **Етап верстки:** Написання семантичної HTML-розмітки для 6 сторінок (Головна, Послуги, Портфоліо, Деталі, Контакти, 404).
3. **Стилізація та адаптив:** Налаштування модульних сіток та забезпечення коректного відображення на мобільних пристроях.
4. **Інтеграція JS:** Додавання базової інтерактивності (скрол-поведінка).
5. **Тестування та деплой:** Валідація коду через сервіси W3C, перевірка швидкодії та публікація на GitHub Pages.

---

##  Використаний інструментарій
* **HTML5:** Семантична розмітка з використанням тегів `<header>`, `<nav>`, `<section>`, `<footer>`.
* **CSS3:** Гнучке позиціонування за допомогою **Flexbox** та побудова галерей через **CSS Grid Layout**.
* **JavaScript:** Базові скрипти для взаємодії з BOM/DOM (відслідковування позиції скролу).

---

##  Ключовий функціонал проєкту

Проєкт відповідає вимогам до сучасних корпоративних сайтів і включає:
*  **Адаптивний Header та навігація:** Шапка сайту з логотипом та меню, яке підсвічує поточну активну сторінку.
*  **Модульні сітки (Grid Layout):** Організація карток у розділах "Послуги" та "Портфоліо" у вигляді рівномірної плитки, яка автоматично перебудовується під розмір екрану.
*  **Плавний скрол (Back to top):** Інтерактивна кнопка на JavaScript, яка з'являється лише після прокручування 300px вниз і плавно повертає користувача нагору.
*  **Форма зворотного зв'язку:** Робоча структура форми на сторінці контактів із блокуванням порожніх відправлень (атрибути `required` для полів імені та email).
*  **Уніфікований UI:** Спільні стилі для кнопок, заголовків та секції футера на всіх підпорядкованих сторінках.

---

##  Адаптивна сітка (Breakpoints)
Для забезпечення кросбраузерності та адаптивності використано медіа-запити:
* **Мобільні девайси (до 767px):** Перебудова Grid-сіток послуг та портфоліо в одну колонку для зручного читання.
* **Планшетні ПК (768px - 991px):** Компактне відображення карток (по 2 в ряд) та оптимізація відступів.
* **Десктоп (992px і вище):** Повноцінне відображення всіх блоків та ефектів наведення (`hover`).
